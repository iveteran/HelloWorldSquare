MacOS通过X.Org Server运行远程Linux主机下的GUI App

# 1. Install
brew install --cask xquartz

# 2. 配置权限（关键）
启动 XQuartz
点击顶部菜单栏 XQuartz -> 设置 (Settings) -> 安全性 (Security) 选项卡
勾选 “允许来自网络客户端的连接” (Allow connections from network clients)

# 3. 设置本地的 DISPLAY 变量（macOS 端的路径）
export DISPLAY=:0

# 4. 授权
1) 基于xauth
需在安装完xquartz后重启终端，或在Xquartz菜单->Applications->Terminal打开终端
xhost +remote_ip  # 添加remote IP，如192.168.0.100, 可将此行加入~/.xinitrc使永久生效
xauth list        # 查看cookies
2) 基于ssh x11 forwarding
需要remote的sshd服务开启x11 forwarding
ssh -Y <user@remote>

# 5. Remote Linux host
1) 基于xauth
export DISPLAY=macos_ip:0 (OrbStack: export DISPLAY=host.orb.internal:0)
2) 基于ssh x11 forwarding
确保/etc/ssh/sshd_config有如下配置:
```
X11Forwarding yes
X11UseLocalhost yes
```
ssh会自动配置$DISPLAY
remote机器上执行: echo $DISPLAY
会输出: localhost:10.0

# 6. 测试功能
sudo apt install x11-apps
xeyes

# 解决“背景黑屏”残留问题
如果即便运行单程序也有黑屏背景，检查 XQuartz 的设置：
打开 XQuartz 设置 -> 选项卡：输出 (Output)
取消勾选 “全屏模式” (Full-screen mode)
确保 “Colors” 设置为 “From Display”
重启 XQuartz

# tips:
隐藏Xquartz: Command + h

# 支持声音
1) Local(macOS)
brew install pulseaudio
pulseaudio --load="module-native-protocol-tcp auth-anonymous=1" --exit-idle-time=-1
注意：auth-anonymous=1 在局域网内较方便，但有安全风险。如果在公网请配置 Cookie 认证

2) Remote(Linux)
export PULSE_SERVER=tcp:macos_ip:4713
